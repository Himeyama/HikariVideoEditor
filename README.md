## ビルドと起動

Visual Studio 2022 の Windows App SDK / WinUI と .NET デスクトップ開発環境、Windows SDK が必要です。

```powershell
.\build.ps1
```

ビルドに成功すると、作成したアプリを自動で起動します。起動しない検証用ビルドは `.\build.ps1 -SkipLaunch` を使用できます。
起動中のアプリを残して更新版を確認する場合は、`.\build.ps1 -OutputDirectory .\bin\SettingsLayout` のように別の出力先を指定できます。

Windows App SDK はアプリの出力に同梱します。.NET 8 Desktop Runtime が別途必要です。通常の `dotnet build` は環境によって Visual Studio の PRI ビルドタスクを見つけられないため、上記スクリプトを使用してください。

画面は Mica を背景に、WinUI 標準のコントロールスタイルとテーマリソースを使用し、システムのライト／ダーク設定に追従します。独自のアクセント色や角丸の上書きは行いません。タイトルバーは XAML で作成しています。タイトルバーのドラッグ・ダブルクリックによる最大化と標準のウィンドウ操作ボタンを維持しています。Per-Monitor V2 の DPI 設定を宣言し、画面の寸法は XAML の論理単位で扱います。初期ウィンドウサイズとタイトルバーのボタン用余白はモニターの倍率に合わせて補正します。

## 編集

確認用の最新版: `bin/StatusUpdate/VideoEditor.exe`。

1. 「ファイル → 素材を追加」で動画・画像・音声を読み込みます。
2. プレビューの下にある時間バーと、その右側の再生・停止・フレーム送りで再生位置を変更します。左右キーで1フレームずつ戻る／進む操作、Space キーで再生／一時停止を切り替えます（文字入力中は入力を優先）。操作ボタンは背景なし・間隔 4 DIP です。タイムラインの目盛り・空白部分を押したまま左右にドラッグしてシークできます。赤い縦線自体もつかんで移動できます。再生中のドラッグは一時停止して追従し、離すと再生を再開します。赤い縦線が現在位置です。停止中やドラッグ中は、指定時刻の映像フレームを表示します。
3. Ctrl＋クリックで素材を選択に追加／解除し、Ctrl＋ドラッグで範囲内の素材を追加選択できます。選択した素材の中央をドラッグすると相対的な時間差・レイヤー差を保ってまとめて移動します。タイムラインのクリップ中央をドラッグすると時間方向に移動し、上下へドラッグするとレイヤーを移動します。他の素材の開始・終了が8 DIP以内に近づくと端同士が吸着します。長さ変更にも吸着が働きます。
4. 左右の端にある 8 DIP 幅のハンドルをドラッグすると長さを変更します。端にマウスを置くと左右矢印カーソルになり、ドラッグ中も維持します。動画・音声は素材の範囲内でトリミングできます。画像は延長できます。
5. クリップを選択して「編集 → 再生位置で分割」、またはクリップの右クリックメニューで分割できます。両側に最低 1 フレームが必要です。
6. 右の設定欄は左ラベル・右入力の配置で、秒数は小数2桁で表示します。数値で編集する場合は設定欄で入力後にEnterを押すと反映し、フォーカスが外れます。「編集 → 設定の変更を適用」からも反映できます。不正入力では編集内容を適用せず元の値へ戻し、該当欄にフォーカスを残します。「編集 → 元に戻す」でドラッグ・トリミング・分割を戻せます。
7. 「ファイル → 動画を書き出す…」で画質（5 / 10 / 20 Mbps）を選び、保存先を指定するとタイムライン全体をMP4（H.264 / AAC）で書き出します。解像度・30 fps・音声周波数はプロジェクト設定を使用します。進捗画面からキャンセルでき、書き出し成功後に保存先へ反映します。プロジェクト保存・再読み込みも「ファイル」メニューから行えます。

画像・動画は青、音声は赤です。レイヤーは初期8段で、画面上側のレイヤー（小さい番号）ほど前面です。最後のレイヤーを使うと次の空レイヤーを自動で追加します。編集操作の時間は 30 fps のフレーム単位に揃えます。余白・間隔・レイヤーの高さは 8 DIP 単位です。素材幅と位置は時間に応じて計算するため、8 DIP 単位には丸めません。HiDPI では DIP を表示倍率に応じて拡大します。

同一レイヤーの時間重複は Windows MediaOverlayLayer の仕様に従います。重ねる素材は別レイヤーに配置してください。対応コーデックは Windows のメディア機能に依存します。

## 動画のダウンロード

現在はメニューから非表示にしています。機能の実装は保持しています。以下は再表示した場合の操作説明です。

「編集 → 動画をダウンロード…」から動画の URL を入力し、「動画情報を取得」でタイトル・長さ・取得可能な画質を確認します。「保存先を選択」で MP4 の保存先を指定するとダウンロードを開始します。「完了後にタイムラインへ追加」も選べます。保存先が現在表示中のワークスペースにある場合は、素材一覧にも反映されます。

「ワークスペースにダウンロード」を選ぶと、素材一覧で現在開いているフォルダーへ動画タイトルをファイル名として直接保存します。同名のファイルがある場合は番号を付け、上書きしません。ワークスペース未選択時は、このボタンは無効になります。

対応する動画共有サービスの単体動画 URL・短縮 URL・ショート形式の URL を受け付けます。任意のサイトからの取得には対応していません。H.264 の映像と AAC の音声を対象とし、別々に配信される場合は Windows の動画処理で MP4 にまとめます。この処理には再エンコードを伴います。通信失敗時は最大2回再試行し、進捗画面からキャンセルできます。途中のファイルは削除し、既存ファイルの置き換えは保存成功時だけ行います。

アカウントを使用しない匿名セッションで取得します。通常の取得で保存可能な配信情報が得られなければ、複数の再生方式と独立したプライベート再生環境を順に試します。普段のブラウザーのプロファイルやログイン情報は読みません。プライベート再生環境には WebView2 Runtime が必要です。署名処理は配信元のプレイヤーに実行させ、実際に返された配信 URL を確認します。アプリ自身が配信元のスクリプトを解析・移植する方式ではありません。

直接配信に加え、暗号化されていない終了済みの分割配信にも対応します。配信一覧が取れても実データへの接続が拒否される形式は、画質の選択肢に出しません。ログイン・本人確認が必要な動画、暗号化された配信、ライブ、プレイリスト、一部の専用配信方式には現在対応していません。配信元の仕様変更によって取得できなくなる場合があります。外部ダウンロードソフトやそのライブラリは同梱・呼び出しせず、通信と保存処理を独自に実装しています。

## ワークスペース・素材の配置

左のフォルダーボタン、または「ファイル → ワークスペースを選択」からディレクトリを選びます。選択画面は WinUI 3 の独自コンポーネントで、標準のボタンを使用します。ホームボタンからユーザーフォルダーに移動できます。パスの入力、上のフォルダーへの移動、フォルダーのダブルクリックに対応します。ワークスペースのフォルダーはプロジェクトに保存されます。

ワークスペース内のフォルダーをダブルクリックすると移動し、動画・画像・音声をダブルクリックすると、赤い再生位置から始まる素材として追加します。素材全体の時間帯で重ならないレイヤーを1から探し、最小の空きレイヤーへ配置します。同じ時間帯のレイヤーがすべて埋まっている場合は、新しいレイヤーへ配置します。素材ファイルの右クリックからも追加と標準アプリでの起動ができます。

タイムラインの素材を右クリックすると「複製」「再生位置で分割」「動画／画像／音声を開く」「削除」が使えます。複製は同じレイヤーの元素材の直後に配置し、トリミング・音量・位置・拡大率を保持します。元ファイル自体は複製しません。

停止中のプレビューで素材をクリックして選び、本体をドラッグすると移動します。角ではサイズ変更の矢印を表示し、ドラッグすると反対側の角を固定して縦横比を保って拡大縮小します。辺では幅または高さだけを変更できます。字幕の選択枠は文字の周囲に収まります。素材を移動してフレームの端・角へ近づけると吸着します。移動と拡大縮小は「元に戻す」、プロジェクト保存、MP4 出力に対応します。動画フレームの外側はグレー、フレーム内の空白は黒です。

ステータスバーの左端は「hh:mm:ss.ミリ秒 | 現在フレーム / 総フレーム」で、フレーム番号は1始まりです。右端は「ワークスペース名 | 解像度 | フレームレート | 音声周波数」です。既定の出力設定は1920x1080、30fps、44.1kHzです。右下の表示をクリックすると動画設定ダイアログを開き、解像度・フレームレート（24/25/30/50/60fps）・音声周波数（44.1/48kHz）を変更できます。左下の時刻・フレーム表示をクリックすると指定秒への移動ダイアログを開きます。表示には実際に書き出しへ渡す設定を使います。

## 外部アプリ・LLM 連携

アプリ起動中は MCP Streamable HTTP のエンドポイント `http://127.0.0.1:53100/mcp` を公開します。標準ポートは53100で、使用中の場合は53101、53102と1ずつ増やして接続可能な番号を選びます。複数起動時は各アプリが異なるポートを使用します。右下のワークスペース名の左に実際の番号を `:53100` の形で表示します。クリックすると、アプリの概要・ポート番号・説明URL（GET /docs）・操作先URL（POST /mcp）を含む生成AI向けプロンプトとコピーボタンを表示します。本文はスクロール可能な選択可能テキストです。

IPv4ループバックだけで待ち受け、外部ネットワークには公開しません。Originヘッダーは同一ポートのlocalhost/127.0.0.1だけを許可します。認証はなく、このPC上の別プロセスから操作できます（従来の同一Windowsユーザー限定ではありません）。LLMやAPIキーは内蔵していません。ローカルHTTPへ接続できるMCPクライアントが必要です。

通信はUTF-8のJSON-RPC 2.0です。`initialize` → `notifications/initialized` → `tools/list` → `tools/call` の順で利用します。対応バージョンは2025-11-25、2025-06-18、2025-03-26です。POSTのContent-Typeはapplication/json、Acceptはapplication/jsonとtext/event-streamを指定し、初期化後はMCP-Protocol-Versionヘッダーを送信します。セッションIDは使用しません。応答はapplication/json、通知は本文なしの202です。サーバー起点のSSE配信は提供せずGET/DELETEは405を返します。リクエスト本文上限は256 KiBです。

```json
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"example","version":"1.0"}}}
{"jsonrpc":"2.0","method":"notifications/initialized"}
{"jsonrpc":"2.0","id":2,"method":"tools/list"}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"clip_add","arguments":{"path":"C:\\Media\\movie.mp4"}}}
```

アプリ起動中は `GET http://127.0.0.1:<実際のポート>/docs` で概要、接続手順、HTTPヘッダー、JSON-RPCリクエスト例、使用法、全ツールの入力スキーマを取得できます。本文なしのGETを使用してください。

公開ツール（入力スキーマはtools/listで取得）:

| ツール | 引数 | 内容 |
|---|---|---|
| `project_get` | なし | プロジェクト全体を取得 |
| `clip_add` | `path`, 任意の`atPlayhead` | 素材を追加 |
| `clip_update` | `id`, 任意の`start`, `trim`, `duration`, `layer`, `volume`, `offsetX`, `offsetY`, `scale` | 素材を変更 |
| `clip_duplicate` / `clip_delete` | `id` | 複製・削除 |
| `clip_split` | `id`, 任意の`seconds` | 絶対秒で分割（省略時は現在位置） |
| `selection_get` | なし | 選択状態を取得 |
| `selection_set` | `ids` | 選択状態を変更 |
| `selection_move` | `seconds`, `layers` | 相対移動 |
| `workspace_set` | `path` | ワークスペース選択 |
| `project_save` / `project_open` | `path` | 保存・読み込み |
| `preview_refresh` | なし | 編集をプレビューに反映 |
| `playback_get` | なし | 再生位置・状態の取得 |
| `playback_play` / `playback_pause` | なし | 再生・一時停止 |
| `playback_seek` | `seconds` | シーク |
| `export_mp4` | `path` | MP4出力（既存ファイルは拒否） |

ツールの結果はcontentのtextにJSONを格納します。編集処理の失敗はisError:true、プロトコルの誤りはJSON-RPCのerrorで返します。編集操作はUI操作と直列に処理します。編集後はpreview_refreshを呼び出してください。MP4出力は完了後に応答します。進捗通知はありません。

PowerShellクライアントは従来のメソッド名をMCPツール名に変換します。戻り値は既存スクリプト互換のid/resultまたはid/error形式です。

```powershell
.\tools\Invoke-Editor.ps1 -Port 53100 -Method project.get
.\tools\Invoke-Editor.ps1 -EditorProcessId (Get-Process VideoEditor | Select-Object -First 1).Id -Method project.get
```

名前付きパイプ方式は廃止しました。ビルド・実行には.NET 8 ASP.NET Coreランタイムが必要です。

## パネルの境界と外観

アプリ名の表示を外し、メニューをカスタムタイトルバーの左側に配置しています。右側の空白部分はウィンドウをドラッグする領域です。ワークスペースの表示は現在のディレクトリ名だけで、完全なパスはツールチップで確認できます。

ワークスペースとプレビュー、プレビューとオブジェクト設定、上段とタイムラインの3つの境界をドラッグできます。境界位置は8 DIP単位で保存し、次回起動時に復元します。保存先は %LOCALAPPDATA%/HikariVideoEditor/layout.json です。画面が小さい場合はプレビューと操作領域を残すように表示サイズを制限します。

## コード構成

編集データは Project.cs、タイムライン操作は TimelineEditing.cs、素材の配置計算は ClipGeometry.cs、プレビュー上の操作は PreviewTransformEditing.cs に分けています。フォルダー選択は FolderBrowser、ワークスペースは Workspace.cs、保存は ProjectFiles.cs、書き出し画面は Export.cs、動画生成は VideoExport.cs、外部APIは ExternalCommands.cs が担当します。配置計算はプレビューと出力で共有しています。既存のC#とXAMLも整形しています。

秒数欄は0.00形式で表示します。ステータスメッセージは最後の表示変更から3秒後に消去し、再生位置とプロジェクト情報は引き続き表示します。



## 字幕・設定

- 「編集 → 字幕を追加…」でテキスト・開始時刻・長さ・フォント・サイズ・位置を設定します。白文字・黒縁の字幕を透過合成し、停止中／再生中のプレビューとMP4出力へ反映します。新しい字幕は空レイヤーへ配置します。重ね順は画面上側のレイヤーを優先します。
- 字幕の右クリック「字幕を編集…」または「編集 → 字幕を編集…」から変更できます。移動・長さ変更・分割・複製・削除・元に戻す・プロジェクト保存に対応します。字幕のテキストと書式はプロジェクトに保存し、表示用画像は必要時に再生成します。
- 「ファイル → 設定…」でアプリ倍率（37.5〜200%）と、新しい字幕のデフォルトフォント・サイズ・上下左右／中央の配置・端からの余白を保存できます。設定はアプリ内のページで表示します。同じ種類の設定は区切り線でつないだブロック、異なる種類は別ブロックで表示します。サイズと余白は動画上のpx単位です。
- 設定保存先: %LOCALAPPDATA%/HikariVideoEditor/settings.json。字幕の描画キャッシュ: 同フォルダーの subtitles。
- ワークスペース見出しの更新ボタンで、現在表示中のフォルダーを再読み込みします。音声素材は音符アイコン、タイムラインでは赤色のブロックで表示します。



タイムラインの右クリック「字幕の追加」から、クリックした時刻・レイヤーに字幕を追加できます。テキストは必須です。書式はオプションで、未指定項目は「値 (規定)」としてアプリの既定値を使用します。初期フォントは Noto Sans JP です。

オブジェクト設定の数値欄には上下の調整ボタンを表示し、ボタン操作を即時反映します。手入力はEnterでも確定できます。

設定ページは左上に配置し、戻るボタンは透明背景としています。各項目の有効な変更は自動保存されるため、保存ボタンはありません。ステータスバーは再生位置・ワークスペース名・解像度・フレームレート・周波数を個別のボタンとし、上下の余白と標準のホバー表示を設けています。

オブジェクト設定ではレイヤーの下限は1、音量の下限は0です。音量は小数2桁で表示し、矢印操作の丸め誤差を除去します。

選択中の素材は素材色の点線で表示します。字幕は右側のオブジェクト設定でもテキスト・書式を変更し、「字幕の変更を適用」で反映できます。拡大時は文字の輪郭から描画し直し、拡大率に合った解像度の画像を使用します。

編集画面と設定ページは標準のFrameナビゲーションとNavigationThemeTransitionで移動します。設定項目は画面幅に合わせて広がります。ステータスバーの上下余白をそろえています。


表示倍率に37.5%、50%、80%、90%、95%を追加しました。タイムラインは左寄せで表示領域いっぱいに広がり、画面のサイズ変更にも追従します。素材の長さが表示領域を超えた場合は横スクロールできます。



字幕の輪郭はWinding規則で塗りつぶし、線が重なる部分の欠けを防止します。プレビューと動画出力は上側のレイヤーを前面として同じ順序で合成します。ワークスペースの長いファイル名は末尾を省略し、ツールチップで全文を表示します。

## 音声と画像を作成

「ファイル → 音声を作成…」で原稿、Windowsの音声、速度、音量、WAV保存先を指定できます。「ファイル → 画像を作成…」では見出し・本文・フッターと色を指定し、プロジェクトの解像度でPNGカードを描きます。作成時の「再生位置に追加する」でタイムラインに配置できます。画像は文字と図形の描画で、生成AIは使用しません。両機能ともこのPC内で動作し、APIキーは不要です。

MCPには speech_voices、speech_create、image_create を公開しています。詳しい引数は起動中のアプリの /docs と tools/list で取得できます。path省略時はワークスペース（未設定ならドキュメント）のGeneratedフォルダーに保存します。既存ファイルの上書きは拒否します。addToTimelineは既定false、startは既定で再生位置、画像のdurationは既定5秒です。追加後はpreview_refreshを呼んでください。音声のvoiceはspeech_voicesが返すIdまたはNameを指定します。

検証: dotnet run --project tests/MediaGenerationChecks/MediaGenerationChecks.csproj（Windowsの実音声とPNG出力、既存ファイル保護、入力制限を確認）。
